ОСНОВНЫЕ ДАННЫЕ
Наружный верх 900×900 мм; низ 850×850 мм; высота корпуса 1000 мм без колес.
Сталь 09Г2С: стенки и днище 2 мм, колесные пластины 4 мм.
Два колеса неповоротных, два поворотных; приняты Ø160 мм.
Расчетный геометрический объем с учетом стенки/днища ≈ 0,757 м³.
Расчетная общая высота в модели 1180 мм.

DXF выполнены в миллиметрах, слой CUT содержит только замкнутые контуры.
Подписи находятся на слое INFO. Компенсация ширины реза не внесена.
Раскладки предназначены для импорта в CAM; машинный NC/G-code необходимо
постпроцессировать под конкретный станок, инструмент и технологию.

ПРИНЯТЫЕ ДОПУЩЕНИЯ И ПРОВЕРКА ПЕРЕД ИЗГОТОВЛЕНИЕМ
Образец формы: открытый стальной контейнер с сужением к днищу.
Референс: https://www.metallid.ru/urny-kontejnery-tbo
Низ 850×850 выбран расчетом для сохранения емкости 0,75 м³.
Крышка, захваты мусоровоза, ручки и дренаж не предусмотрены, так как не заданы.
Перед производством выбрать конкретные колесные опоры и подтвердить отверстия
80×60 мм, грузоподъемность, тормоз и высоту вилки/кронштейна.
Подогнать угловые стыки листов и назначить допуски/режим сварки по ТП предприятия.
Модели колес показывают габарит Ø160×40 мм, без конструкции поворотного узла.

ЗАПУСК ПРОГРАММ
Python 3.13, pywin32, ezdxf, reportlab; для build_cad.py нужен SolidWorks 2026.
Команда: python build_cad.py ПУТЬ_К_ПУСТОЙ_ПАПКЕ
Команда: python build_docs.py ПУТЬ_К_ПАПКЕ
build_cad.py не перезаписывает существующие файлы.
