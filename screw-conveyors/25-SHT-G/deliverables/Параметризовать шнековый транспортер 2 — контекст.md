## Согласованные параметры и правила

- Длина рабочей части желоба **2885 мм**. Значение 3004 мм было отменено пользователем.
- Исходный шнек: наружный диаметр **200 мм**, шаг **200 мм**.
- В исходной спецификации по две опоры корпуса `25.SHT.G.01.01.00.00` и `25.SHT.G.08.00.00.00`. Оба исполнения добавляются поровну.
- Последнее и действующее правило: расстояние между соседними опорами корпуса **не более 3000 мм**. Количество опор каждого исполнения: `ceil(L / 3000) + 1`. При L=2885 мм — по 2, при L=3001 мм — по 3. Реализовано в `support_layout.py`, отображается в Tkinter, проверено на граничных длинах.
- Предыдущее предложение выбирать количество опор по прогибу пользователь отменил. Для правила 3 м не требуются ответы о материале и влажности.
- Промежуточные опоры вала применяются только для трубных транспортёров. Текущая модель — желобная.
- Покупные изделия: исходный **редактируемый** перечень 27 позиций (41–44 и 63–85 исходной спецификации). Можно выбирать строки, менять количество, добавлять изделия и экспортировать раздел спецификации в CSV.
- Пользователь хочет автоматический пересчёт количеств при изменении длины и числа опор. Сейчас автоматически вычисляется количество самих опор корпуса; крепёж и другие покупные позиции ещё не привязаны к опорным узлам. Не утверждать, что полная спецификация пересчитывается автоматически.

## Материал как отдельный незавершённый сценарий

В ходе проверки пользователь предложил мелкую свинцовую руду как тяжёлый тестовый груз. По таблице KWS верхняя справочная насыпная плотность **4325 кг/м³**, расчётная крупность **3,2 мм**. Пользователь указал влажность **80 % воды по массе влажной смеси**. Справочная плотность руды не является подтверждённой плотностью такой смеси. `validation.py` помечает её статусом `requires_wet_material_confirmation`, а `strength.py` не рассчитывает по ней массу партии и массовый расход. Пользователь затем прервал уточнение состава смеси и вернулся к простому правилу опор через 3 м. Не возобновлять вопросы о материале без нового запроса.

Источник справочной плотности: https://www.kwsmfg.com/engineering-guides/screw-conveyor/bulk-material-table/
