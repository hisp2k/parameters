  при `cut == null` для `Dir=true` выполняется одна повторная попытка с
  `Dir=false` перед тем, как вернуть `CUT_FAILED`.

## Важные особенности SOLIDWORKS 2026

- «Бобышка-Вытянуть» возвращается как `IFeature.GetTypeName2() = Extrusion`.
- `IDimension.GetType()` может вернуть `swDimensionTypeUnknown` для реального
  линейного управляющего размера. Исключение разрешено только известным `AI_*`,
  созданным коннектором по фиксированной схеме.
- Полное имя размера содержит имя документа и после повторного открытия должно
  читаться заново; старое имя не используется вслепую.

## Ключевые исходники

- `src/Protocol.cs` — MCP-протокол и строгие схемы.
