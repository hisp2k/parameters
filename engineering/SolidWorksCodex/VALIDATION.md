«Бобышка-Вытянуть» возвращается API как `feature_type=Extrusion`, а созданные
управляющие размеры могут возвращать `dimension_type_code=0` при корректных
`system_value_si`, `driving=true` и `read_only=false`. Версия 2.2.2 учитывает оба
факта только для известной схемы созданных коннектором линейных `AI_*`.

## Живая проверка 2.2.2

Исправление 2.2.2: `sw_features` группирует общий проверенный список размеров
из того же источника, что и `sw_parameters`. Контрольный тест повторно открывает
точный `file_path`, возвращённый созданием пластины.

Исправление 2.2.2: тестовая проверка SHA-256 открытого SLDPRT использует
`FileShare.ReadWrite | FileShare.Delete` и не конфликтует с блокировкой файла
процессом SOLIDWORKS.

Исправление 2.2.2: наличие установленного PDM-клиента само по себе больше не
блокирует обычную локальную папку. Путь блокируется как PDM только тогда, когда
PDM API действительно вернул имя хранилища.

Версия сохраняет безопасный режим Workspace и добавляет запись в существующие
SLDPRT/SLDDRW на проверенном локальном фиксированном диске. Сеть, съёмные диски
и пути через точки повторной обработки должны быть отклонены.

1. Распаковать архив и запустить `INSTALL.cmd`.
2. Запустить один SOLIDWORKS 2026 от того же пользователя.
3. Выполнить установленный `CHECK.cmd`.
4. Выполнить `CREATE_TEST_SHEET_CONTOUR.cmd` и `CREATE_TEST_POLYGON_CORNERS.cmd`.
5. При необходимости выполнить `CREATE_TEST_WORKSPACE_DRAWING.cmd`.
6. Первый успешный результат должен содержать:
   - `connector_version = 2.2.2`;
   - деталь `PLATE_120x80x6_4xD10_*.SLDPRT` находится в локальной Workspace;
   - проверка объёма детали имеет статус `PASS`;
   - тест явно открывает только что созданную SLDPRT из Workspace;
   - `sw_parameters` находит `AI_Length`, `AI_Width` и `AI_Thickness`;
   - `sw_create_parameter_variant` оставляет исходную деталь 120×80×6 мм
     неизменной, создаёт вариант 140×90×8 мм и возвращает
     `verification.status = PASS`;
   - повторное чтение подтверждает все три значения и габарит ≈ 140×90×8 мм;
   - чертёж `*_DRAWING_*.SLDDRW` находится в той же Workspace;
   - `projection = first_angle`;
   - `verification.status = PASS` и `referenced_model_view_count >= 1`;
   - в детали пятнадцать настоящих размеров помечены для чертежа;
   - `display_dimension_count >= 15` после переноса размеров в SLDDRW;
   - отдельный `sw_drawing` возвращает `verification.status = PASS`;
   - новый PDF находится в Workspace, имеет сигнатуру `%PDF-`, а исходный
     SLDDRW остаётся неизменным.

Контрольная геометрия сначала создаётся как пластина 120×80×6 мм с четырьмя
сквозными отверстиями Ø10 и отступами центров 15×15 мм. Затем создаётся отдельный
вариант 140×90×8 мм; положение отверстий остаётся заданным отступами. Чертёж содержит стандартные виды, длину,
ширину, толщину, четыре диаметра и восемь размеров положения отверстий.

6. Выполнить `CREATE_TEST_LOCAL_DISK_EDIT.cmd`.
7. Второй успешный результат должен содержать:
   - открытие тестовой SLDPRT вне Workspace через `sw_open_local_file`;
   - `storage_scope = LOCAL_FIXED_DISK` и `connector_write_allowed = true`;
   - изменение локальной копии с 120×80×6 до 135×85×7 мм;
   - отдельную резервную SLDPRT с SHA-256 исходного файла до изменения;
   - проверенное назначение свойств и `AISI 304` с ещё одной резервной копией;
   - новый SLDDRW и PDF рядом с локальной деталью, но вне Workspace;
   - неизменность SHA-256 детали при создании чертежа и чертежа при экспорте PDF;
   - итоговую строку `PASS: local fixed-disk open, backup, edit, properties, drawing and PDF passed; network paths remain blocked.`

8. Выполнить `CREATE_TEST_FEATURE_EDIT.cmd`.
9. Третий успешный результат должен подтвердить:
   - чтение дерева через `sw_features`;
   - точные `feature_name` и `feature_type = Extrusion`;
   - линейный управляющий размер `AI_Thickness`, непосредственно принадлежащий
     выбранному элементу;
   - резервную копию перед изменением;
   - изменение толщины с 6 до 9 мм;
   - успешное перестроение, неизменное число твёрдых тел, положительный объём,
     проверенное значение размера и сохранение;
   - итоговую строку `PASS: exact Extrusion feature identity, owned linear dimension, backup, rebuild, geometry and save passed.`

## Критерии сбоя

Сбой — ошибка коннектора, отсутствие файла, любой статус проверки кроме `PASS`,
не одно твёрдое тело, неверный набор цилиндров, неподтверждённый материал или
свойства. Ошибочный новый документ закрывается и удаляется. Перед разрешённым
изменением существующего локального файла создаётся проверенная резервная копия;
при ошибке изменения параметров коннектор пытается вернуть исходные значения в
памяти. При сбое нужен полный текст окна одного запуска.

В 2.2.2 `sw_set_parameter`, `sw_set_parameters` и `sw_create_parameter_variant`
по-прежнему работают только с `AI_*`. Отдельная команда
`sw_set_feature_dimensions` может менять обычные линейные управляющие размеры,
но только если они непосредственно принадлежат одному точно выбранному элементу
типа `Extrusion`, `Boss`, `Cut`, `HoleWzd`, `Chamfer` или `Fillet`. Она не параметризует STEP,
не меняет размеры эскизов и не создаёт новые элементы. Plan v5 обрабатывает только четыре
вертикальных угла прямоугольного выступа. Фаски верхних/нижних кромок,
произвольный выбор рёбер, вложенные и многоуровневые выступы, резьбы,
пересекающиеся операции и произвольные материалы пока не поддерживаются.
Производственное одобрение не выдаётся.
