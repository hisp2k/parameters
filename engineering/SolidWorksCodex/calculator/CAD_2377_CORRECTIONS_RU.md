## Что исправлено в калькуляторе

- cad_layout_readback хранит результат чтения состава; cad_sync остаётся
  незавершённым до полноценной проверки CAD. Подсчёт не закрывает коллизии,
  посадки, шнек, привод и BOM.
- Некорректные, неполные и противоречивые страницы не дают достоверных счётчиков.
- Имена найденных экземпляров и контекст сохраняются. Подсчитываются только
  экземпляры верхнего уровня, а не предполагаемое число стыков.
- Две проставки не превращаются в три логическим выводом. Если количество
  проставок не совпадает с числом стыков, оценка длины не публикуется.
- Изменение снимка поднимает ревизию и аннулирует зависимые подтверждения.
  Сбой чтения убирает прежние измерения из текущих параметров.
- Старые проекты, в которых подсчёт секций закрывал cad_sync, требуют
  повторной проверки после загрузки. Данные проекта не удаляются.

## 3. Зафиксировать длину без подмены определения

Четыре номинала по 3000 мм дают 12000 мм без межсекционных проставок.
При трёх стыках по 2 мм оценка цепочки — 12006 мм.
Шаг массива при такой схеме — 3002 мм; базы секций относительно первой:
0, 3002, 6004, 9006 мм. Это расчётная схема для сверки, не новые CAD-замеры.

Измерить фактическую цепочку, полный габарит с торцевыми узлами и рабочую
длину/расстояние между патрубками отдельно. Не округлять 12006 до 12000.
Если требование относится к точному полному габариту 12000 мм, зафиксировать
противоречие и согласовать изменение секций до изменения их размеров.

## 4. Шнек и привод

Один исходный экземпляр «Шнек с осями» не подтверждает работу по всей длине.
Сначала определить рабочую трассу, секционирование шнека, опоры, соединения,
требуемые зазоры и доступность сборки. Использовать реальные характеристики
груза, подачу, обороты, геометрию, материалы и каталог привода.

Проверить прочность, прогиб, критические частоты/динамику по применимости,
подшипники, рабочий и пусковой момент, привод и защиту. Не растягивать
исходный шнек до 12 м без подтверждения этих решений.
Если исходных данных нет — выдать один список конкретно недостающих полей,
продолжив независимые исправления корпуса.
