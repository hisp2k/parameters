# Шрифты для PDF (кириллица)

`DejaVuSans.ttf` и `DejaVuSans-Bold.ttf` — шрифты проекта DejaVu Fonts
(на основе Bitstream Vera Fonts), лицензия свободная для встраивания и
распространения без отчислений (см. https://dejavu-fonts.github.io/License.html).

Шрифты вложены прямо в репозиторий, а не берутся из системного пути ОС,
потому что путь `/usr/share/fonts/truetype/dejavu/...` есть только в
Linux-окружении этой облачной сессии и отсутствует на Windows-рабочей
станции пользователя — раньше это делало генерацию PDF с кириллицей
рабочей только в облаке (см. TASK.md, раздел исправленных ошибок,
пункт "В. Кроссплатформенность PDF"). Теперь `documents/agreement_sheet.py`
и любой другой PDF-модуль берут шрифт по относительному пути
`calculator/assets/fonts/`, который одинаков на любой ОС.
