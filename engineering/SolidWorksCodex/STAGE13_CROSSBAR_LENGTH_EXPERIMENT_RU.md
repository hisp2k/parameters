## Чертёж

Оригинальный чертёж `Чертежи\Детали\25.SHT.G.09.00.00.01  Перекладина.SLDDRW`
существует (базовая проверка ранее: 1 лист, 2 вида, 4 отображаемых размера), но
Pack and Go с `IncludeDrawings=true` не скопировал его вместе со сборкой — по всем
признакам `IncludeDrawings` в SOLIDWORKS относится только к чертежу самого
пакуемого верхнеуровневого документа, а не к чертежам дочерних компонентов, даже
предварительно открытым. Ручная перелинковка ссылок оригинального чертежа на
копию признана избыточным риском для эксперимента такого масштаба.

## Исправление коннектора в этой сессии (критично для самой проверки)

При старте сессии `assembly_position_xyz_m` в `TestAudit` всегда возвращал `null` —
то есть до этой правки было ФИЗИЧЕСКИ НЕВОЗМОЖНО проверить требуемое условие задания
«проверить позицию ОБЕИХ пластин». Причина: `Transform2` — это COM-свойство
(property), а код вызывал его через `Call()` (метод `GetMethod`, для методов), что
всегда падало с `API_METHOD_MISSING`, молча проглатываемым обёрткой `Try()`.

- `src/TestExperiment.cs`, `TestAudit`: `Call(component, "IComponent2", "Transform2")`
  заменено на `Get(component, "IComponent2", "Transform2")` (свойство читается через
  `Get`, не через `Call`).
- Туда же добавлено поле `"issues"` в возвращаемый объект `TestAudit` — раньше список
  ошибок, накопленных `Try()`, вообще не попадал в ответ, и такие сбои были не видны
  снаружи. Теперь `issues: []` явно подтверждает отсутствие скрытых сбоев чтения.

Без этого исправления результаты позиций пластин в таблице выше не могли быть
получены никаким способом через существующий коннектор — это не эстетическая
правка, а необходимое условие выполнения задания.

Также в рамках этой же сессионной цепочки работ (до текущего перекомпилированного
шага) в коннектор уже были добавлены: необязательный `include_drawings` для
`sw_test_pack_and_go` (опробован в этом эксперименте — не решил проблему чертежа
дочернего компонента, см. выше, но работает по документированному назначению) и
обязательный `EditRebuild3` перед сохранением DRW в `sw_save_workspace_document`
(защита от сохранения чертежа с неактуальными видами/размерами).

Пересборка выполнена, офлайн-тесты пройдены: `276 + 81 + 74 + 26 = 457` проверок,
exit code 0 (`_claude_build_v4_report.txt`, `_claude_build_v4_exitcode.txt`).
