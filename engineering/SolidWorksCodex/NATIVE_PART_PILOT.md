## Исправления Коннектора

- IDimension.GetType ошибочно расшифровывался через swDimensionType_e.
  Теперь используется swDimensionParamType_e: 0=линейный, 1=угловой,
  2=целочисленный, -1=неизвестный. Удалена подмена типа по имени AI_*/D1.
  Неизвестные и угловые параметры не допускаются к записи в миллиметрах.
- Extrusion добавлен в опубликованную JSON Schema sw_set_feature_dimensions;
  исполнитель уже поддерживал его, но клиентский контракт скрывал этот тип.
- Двойники API и регрессии исправлены; проверяются также реальные enum DLL.

Основание: [IDimension.GetType](https://help.solidworks.com/2020/English/api/sldworksapi/SolidWorks.Interop.sldworks~SolidWorks.Interop.sldworks.IDimension~GetType.html),
[swDimensionParamType_e](https://help.solidworks.com/2025/english/api/swconst/SolidWorks.Interop.swconst~SolidWorks.Interop.swconst.swDimensionParamType_e.html).
