# Правила для Claude

Перед изменениями прочитай:

1. TASK.md
2. PROJECT_STATE.md
3. README_RU.md
4. VALIDATION.md

Работай в ветке claude/<название-задачи>.

Claude выполняет:

- большие изменения кода;
- PowerShell-скрипты;
- тесты;
- обработку PDF;
- преобразование чертежей в компактные JSON-планы;
- документацию.

Обязательные ограничения:

- не разрешать запись в сетевые пути;
- не разрешать запись в PDM;
- обычными инструментами не изменять сборки; единственное исключение:
  явно разрешённый тестовый комплект через sw_test_pack_and_go/sw_test_document
  и локальный TestScope.local.json (см. SCOPED_PARAMETRIC_EXPERIMENT.md);
- не добавлять произвольные COM-вызовы;
- не утверждать прохождение живого теста без проверяемого результата пользователя
  или полного отчёта реальных вызовов коннектора;
- существующие документы не сохранять и не изменять без явной команды;
- созданные модели не считать допущенными к производству.

После работы:

1. Запусти автономные тесты.
2. Обнови TASK.md.
3. Запиши список изменённых файлов.
4. Сделай Git commit.
5. Сообщи hash коммита.
6. Не собирай финальный релизный архив — его проверяет Astra.
