# Stage 11 — найден шаблон опросного листа и BOM-модели для шнекового транспортера

Дата: 16.09.2026 (ночь). Ветка: `claude/director-parametric-pilot`. Продолжение Stage 10.
Полный текст с таблицами — в `status-director-pilot-stage11-questionnaire-template-found.md`
в claude.ai Project `SolidWoksConnetctor`.

## Источник

На связанном компьютере в `Downloads` найдены (созданы позже всех прежних материалов):
`BOM_модели_и_опросные_листы_транспортеров.xlsx` и одноимённый zip
(тот же xlsx + `README_BOM_опросные_листы.md`). Комплект охватывает три семейства —
ленточный, роликовый/рольганг, шнековый транспортер — для каждого опросный лист и BOM-модель.

## Что нашлось

Лист «Опросный_Шнековый» — 50 полей (Общие, Условия, Продукт, Геометрия, Шнек, Корпус,
Привод, Подшипники, Конструкция, Поставка), шаблон без заполненных значений, но с единицами
измерения и признаком обязательности. Лист «BOM_Шнековый» — 20 обобщённых позиций
(покупное/изготавливаемое), без ссылок на конкретные `25.SHT.G.*`. Лист
«Связь_с_себестоимостью» описывает конвейер: опросный лист → инженерное ядро (детерминированные
формулы) → BOM → справочник цен → калькулятор себестоимости → коммерческий расчёт; все этапы
помечены «Готово».

Важные соответствия с уже подтверждённым в Stage 6-10:
- «Рабочая длина по оси» (обязательное поле) = параметр L (в заказе 2377 — 3000 мм).
- «Диаметр шнека» и «Шаг витка» помечены НЕОБЯЗАТЕЛЬНЫМИ с комментарием «пусто = подобрать» —
  это подтверждает, что D200 и шаг 200 мм (Stage 6-10) — расчётные, а не вводимые вручную
  значения по умолчанию.
- «Материал витка» = 09Г2С, «Материал корпуса» = AISI 304 (в заказе 2377) — совпадает с уже
  найденными данными.
- Новые, ранее не встречавшиеся параметры: «Угол наклона» (все изученные CAD-данные — только
  горизонтальное исполнение), «Тип корпуса» (U-образный/трубчатый/спец.), «Исполнение»
  (одновальный/двухвальный — пилот и заказ 2377 однозначно одновальные).

## Чего по-прежнему нет

Сами формулы инженерного ядра для шнекового транспортера не найдены. Отдельный рабочий
калькулятор на этом же компьютере (`Downloads\Transporter_Calculator_FOR_DIRECTOR\
Transporter_Calculator\transporter_calculator.py`, Python/Streamlit) целиком посвящён
ленточным и роликовым транспортерам (ГОСТ 22644-77, ГОСТ 20-2018, ГОСТ 21327-88,
ГОСТ 8324-57) — совпадений по «шнек»/«screw»/«auger» в коде нет.

Блокер «нет опросного листа/формул» сузился: структура опросного листа и BOM теперь есть,
но сама инженерная математика (как из производительности и насыпной плотности получить
диаметр/шаг шнека и мощность привода) для шнекового транспортера остаётся ненайденной —
нужно уточнить у Дмитрия Александровича, существует ли она отдельным файлом или её ещё
предстоит формализовать.
