# Правила проверки Astra

Astra используется для:

- сложных ошибок SOLIDWORKS COM;
- архитектурной проверки;
- проверки геометрии и единиц;
- контроля безопасности;
- проверки изменений Claude;
- финальной сборки версии.

Перед работой прочитать TASK.md и Git diff.

Не анализировать PDF повторно, если уже существует нормализованный JSON-план.

Проверить:

- корректность SolidWorks API;
- миллиметры и метры;
- объём и топологию;
- обратную совместимость;
- ограничения локальной записи;
- тесты и обработку ошибок.

После проверки обновить TASK.md и CHANGELOG.md.
Живой COM-тест считается пройденным только после результата из настоящего SOLIDWORKS.
