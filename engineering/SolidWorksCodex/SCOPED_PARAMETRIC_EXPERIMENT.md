## Минимальное расширение коннектора

- `sw_test_pack_and_go`: явная активация источника без rebuild, Pack and Go в новый
  каталог, точное сопоставление путей, проверка кодов копирования, ссылок и исходников.
  Несохранённый источник не сохраняется; геометрия копии проверяется после загрузки.
- `sw_test_document`: `open`, `audit`, `rebuild_save`, `close`, `reopen` только внутри
  зарегистрированной папки и её полной допустимой цепочки зависимостей.
  Сохранение требует бэкапов, успешного rebuild и проверенного здоровья компонентов.
  Закрытие грязных или используемых другими документами файлов запрещено.
- Размер изменяет прежний `sw_set_feature_dimensions`, без произвольных COM-команд.
- `AlreadyOpen=128` не обходится разрешением любых предупреждений: уже загруженный
  документ активируется без нового OpenDoc6 и получает отдельный статус.
- `swDocNeedsRebuildWarning=2` при активации возвращается явно; затем требуется
  отдельный rebuild/save. Ошибки активации и настоящие ошибки загрузки блокируются.
- Объём считается существующим `VolumeOf` с `UseSystemUnits=true`, очисткой выбора
  внутри тестовой детали и проверкой конечного положительного значения.

Обычный запрет записи сборок сохраняется. Исключение включается локальным, не
публикуемым `TestScope.local.json` рядом с EXE: поле `test_root` должно точно совпасть
с явно разрешённой пользователем папкой. Сеть, PDM, переходы/junction и внешняя запись
не разрешены. Наличие локального файла настройки само по себе не заменяет разрешение.

## Воспроизведение

Запуск из репозитория с уже загруженным исходным узлом 09:

```powershell
$root='C:\Users\adm\Desktop\25.SHT.G.00.00.00.00 СБ'
.\RUN_SCOPED_PARAMETRIC_EXPERIMENT.ps1 -TestRoot $root `
 -SourceAssembly "$root\25.SHT.G.09.00.00.00 СБ  Перекладина съемная.SLDASM" `
 -SourcePart "$root\25.SHT.G.09.00.00.02  Пластина.SLDPRT" `
 -FeatureName 'Бобышка-Вытянуть1'
```

Сценарий каждый раз создаёт новый уникальный вариант, ожидает исходные 4 мм,
последовательно выполняет проверки и записывает полный отчёт в `Reports`.
Таймаут не вызывает автоматического повтора записи. Для явно проверенного продолжения
после уже успешного изменения есть `-ResumeAfterChangeReport`; повторной записи размера
нет, текущие 5 мм подтверждаются заново. Формула объёма в сценарии относится только
к выбранной пластине постоянной толщины, а не к произвольному размеру.
