## Последняя Передача: Черновик инженерного ядра для шнекового транспортера (Stage 12)

НЕ ПРОВЕРЕННЫЙ инженером Тех-Аэро набор формул инженерного ядра для шнекового транспортера
(опросный лист → диаметр/шаг/частота вращения/мощность), поскольку Stage 11 показал, что
готового ядра нигде на связанном компьютере не найдено. Подробности:
`STAGE12_ENGINEERING_CORE_DRAFT_RU.md` в этом репозитории, полный текст с таблицами —
`status-director-pilot-stage12-screw-conveyor-engineering-core-draft.md` в claude.ai Project
`SolidWoksConnetctor`, реализация — `screw_conveyor_core_draft.py` в корне этого репозитория.
Формулы взяты из открытых инженерных источников (не собственность Тех-Аэро), со ссылками в
документе. Проверка на правдоподобие: для типового среднеабразивного случая (5 т/ч) черновик
самостоятельно выбирает диаметр 200 мм — совпадает с фактическим диаметром шнека линейки
25.SHT (реальный заказ №2377). Явно НЕ покрыто: толщина витка/корпуса (нужен прочностной
расчёт), двухвальное исполнение, угол наклона свыше 20°. Требуется подтверждение/калибровка
коэффициентов инженером Тех-Аэро, прежде чем это может стать рабочим ядром.

## Закрытые Ошибки

- Неизвестный GetSaveFlag/read-only больше не допускает запись.
- Save3 после изменения не подменяет проверенный документ новым активным.
- Смена документа/конфигурации останавливает изменение и опасный откат.
- Даже явное сохранение чистого документа защищено проверенным бэкапом.
- Ошибка rebuild после изменения свойств блокирует сохранение.
- Размер эскиза/другого элемента не редактируется через выбранный boss.
- Известный угловой AI_* не принимается за миллиметры. Поддержка старого
  code=0 сохранена только для известной линейной схемы коннектора.
- Скрытые параметры варианта ищутся через общий inventory; неполный
  inventory отклоняется. Копия варианта сверяется по SHA-256.
- Таймауты включают mutex ожидание; feature edit и открытие сборки получают
  длинный бюджет. 45/75 секунд меньше текущего MCP tool_timeout_sec=90.

## Ограничения

Живое изменение/создание варианта новой сборкой ещё не проверено.
Проверять на отдельной тестовой детали/копии с бэкапом, не на транспортёре.
Проверять значения, конфигурацию, rebuild, тела, объём, файл и бэкап.
Не превращать автономный PASS в утверждение о живом результате.

Не расширять разрешения на сборки, сеть, PDM или произвольные COM-вызовы.
При GUI-смене документа/конфигурации после первого изменения исходная
модель может остаться изменённой в памяти, но не сохраняется и не
переключается обратно. Бэкап остаётся; требуется ручная проверка.
Коннектор не даёт транзакции против параллельного GUI-редактирования.

Полный read-only тест предыдущего cb5c28c: 516 экземпляров, 41 прямая
зависимость, 4 отсутствующих файла по сохранённым путям в «СБ Изм.5».
read_only=true вместе с errors=2 означает частичную, не чистую загрузку.
Не подменять ссылки одноимёнными файлами и не считать их ошибкой кода.

Воспроизведённые этим аудитом ошибки закрыты. Это не доказательство
отсутствия любых дефектов геометрического движка или внешних CAD-файлов.
