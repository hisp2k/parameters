# Подготовка расчётной программы шнековых транспортёров

Первый программный этап принимает исходные данные, переводит единицы в SI, выбирает профиль среды и проверяет полноту и совместимость данных. Он **не рассчитывает конструкцию и не разрешает выпуск**.

## Запуск

Python 3.11+; внешние библиотеки не требуются.

```powershell
python preflight_cli.py examples/sludge_input_template.json
python reference/sludge_reference.py
python -m unittest discover -s tests -v
```

Команда проверки возвращает `UNKNOWN` и перечень отсутствующих сведений для шаблона обезвоженного осадка с добавкой песка. Сообщённая влажность песка `60 %` сохраняется отдельно как непроверенное исходное значение: база процента неизвестна. При подтверждённых расходе и плотности **всей смеси** программа выводит диапазон требуемого объёмного расхода. `READY_FOR_ENGINEERING_MODEL` означает только, что входы прошли проверку полноты. Ни один результат этого этапа не имеет статуса допуска конструкции.

## Документы

- `outputs/01_CALCULATION_PASSPORT_v0.1.md` — исходный MVP для горизонтального трубного шнека с сыпучей средой.
- `outputs/02_MEDIA_PROFILES_AND_CHECKS.md` — классификация и данные разных сред.
- `outputs/03_PROGRAM_ARCHITECTURE.md` — целевая архитектура.
- `outputs/04_SLUDGE_CALCULATION_PASSPORT_v0.1.md` — выбранная пользователем первая среда: обезвоженный осадок с добавкой песка.
- `outputs/05_MINIMUM_MEASUREMENTS_FOR_SLUDGE_SAND.md` — минимальный план получения отсутствующих данных.

Файлы `sources/` проекта, если появятся, являются исходными материалами и не редактируются.
