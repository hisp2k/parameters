## Как пользоваться

Для каждого изделия сначала прочитайте его README, контекст или файл статуса. В папках `deliverables` находятся сохранённые результаты, в `development` — программы построения, исправления и диагностики. Снимки `snapshots`, архивы и документы прежних ревизий сохраняют историю; актуальное исполнение указано в статусе проекта.

Интерфейс «Шнека 1» запускается командным файлом `Запустить интерфейс.cmd` рядом с его README. Нужны Windows, SolidWorks и Python с `pywin32`. Требования остальных программ указаны в их документации. Пути в исходных скриптах и старых протоколах сохранены: при работе на другом компьютере проверьте настройки путей и ссылки сборок SolidWorks.

В репозиторий перенесены фактически существующие материалы с их текущими инженерными статусами. Некоторые узлы, расчёты и чертежи являются предварительными; ограничения и следующие шаги записаны в исходных документах соответствующего изделия. Импорт не меняет статус готовности к изготовлению и не подтверждает результаты новым расчётом CAD/CFD.

## Большие архивы

Восемь крупных ZIP/RAR сохранены без изменения в папках `.parts`, частями по 16 МиБ. Такое разбиение позволяет обходить ошибки хранилища крупных объектов при загрузке. Для восстановления исходных архивов выполните из корня репозитория:

```powershell
python tools/restore_large_files.py
```

Программа проверяет размеры и SHA-256 частей и готового архива. Восстановленные архивы не нужно повторно добавлять в Git.
